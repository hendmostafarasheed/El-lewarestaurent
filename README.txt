EL LEWA KEBAB & KOFTA — Luxury interactive mini-site

FILES
- index.html: landing / invitation page with an OPEN MENU hotspot.
- menu.html: menu page with ORDER NOW, menu expand, home navigation, and modal interactions.
- home-el-lewa.png: generated luxury landing-page artwork.
- menu-el-lewa.png: generated menu artwork with ORDER NOW design.
- el-lewa-music.mp3: music file supplied by the user.
- style.css: responsive black-and-gold styling and animated gold droplets falling from the top.
- site.js: button behavior, music controls, modals, and menu lightbox.

HOW TO USE
Extract the ZIP and open index.html in a browser. The OPEN MENU artwork opens menu.html. On the menu page, tap the illustrated ORDER NOW area to open its order dialog, use EXPAND MENU to zoom, and use the floating music control to play/pause the supplied audio.

NOTES
- Browsers commonly block autoplay audio until the visitor taps PLAY MUSIC.
- ORDER NOW is interactive but is not connected to a real ordering service yet. Add the restaurant's verified WhatsApp number or order URL to connect actual orders.
- Location information is presented as New Cairo; the exact street address has not been supplied.
- Prices visible in the generated menu artwork are illustrative and should be confirmed before publication.
